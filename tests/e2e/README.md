# Сквозные проверки и замеры

Нужны Node.js 22+ (встроенные `fetch` и `WebSocket`) и Rust.

## Проверки интерфейса

```
powershell -ExecutionPolicy Bypass -File tests\e2e\run-e2e.ps1
```

Скрипт собирает браузер, запускает отдельную тестовую копию с временной папкой
данных и окном за пределами экрана, управляет ею через отладочный порт WebView2
(9333) и проверяет (21 проверка): вкладки, заставку запуска, меню, параметры по
разделам и поиск по ним, поиск по странице, масштаб, меню адресной строки,
подсказки без мигания, обои и видеообои, цвет, вертикальные вкладки, AMOLED и
прозрачность, боковую панель, менеджер паролей (своя локальная страница входа),
аккаунт с синхронизацией (во временной «облачной» папке), uBlock Origin Lite и
передачу адреса уже открытому окну. После проверок всё временное удаляется.

Видеообои в git не хранятся: после клонирования один раз запустите
`powershell -ExecutionPolicy Bypass -File assets\wallsetch.ps1`.

Ключ `-Release` проверяет релизную сборку. Модульные тесты — `cargo test`.

## Замер против Edge

```
powershell -ExecutionPolicy Bypass -File tests\e2e\bench.ps1 -Runs 3
```

Время до появления окна и память дерева процессов через 12 секунд на локальной
странице `fixture/index.html` (без сети, чтобы не зависеть от VPN). Edge
запускается с отдельным временным профилем — обычный профиль не затрагивается.
