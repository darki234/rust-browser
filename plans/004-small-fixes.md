# 004 — Мелочи: моноширинный шрифт, скругления, цвета мимо палитры, рамка у слоя

**Флаги:** TOUCHES-DS (пункт 3 — цвета через токены). Развилок нет — выполнять можно.

## Проблемы и цели

1. **KR-19 (hard)** — моноширинный шрифт вне кода.
   `src/ui/style.css:1973` `.pw-secret { … font: 13px/1 Consolas, monospace; letter-spacing: .08em; }` (скрытые пароли точками).
   Цель: `font: inherit; font-size: 13px; letter-spacing: .02em;` — точки остаются, шрифт интерфейса.

2. **KR-1 (hard)** — вложенные скругления не согласованы.
   Карточка темы: `.theme-card { border-radius: 12px; padding: 8px; }`, внутри `.theme-card .tp { border-radius: 8px; }` — внутреннее должно быть 12 − 8 = 4px.
   Цель: `.theme-card { border-radius: 14px; }`, `.tp { border-radius: 6px; }` (14 − 8 = 6).

3. **DS-2a** — цвета в обход палитры:
   - `style.css:506–507` `#downloads.dl-done` использует `#3fb950` → `var(--ok)` (токен уже есть в `:root`).
   - `style.css:2441` (тема Ryoku) `… { background: var(--text); color: #000; }` → `color: var(--bg);`.

4. **KR-5 / детектор E-3** — у всплывающего слоя и рамка, и широкая тень:
   `style.css:2307` `#peek { border: 1px …; box-shadow: 0 14px 34px …, 0 2px 8px …; }` — предпросмотр вкладки является слоем, слою достаточно тени.
   Цель: убрать `border`, тень заменить на токен `var(--shadow)`.

## Шаги
Для каждого пункта — заменить указанную строку на целевое значение. Номера строк могут сдвинуться: искать по селектору.

## Не трогать
Белый текст на цветных кнопках (`.text-btn.danger`, `.tile-x:hover` и т. п.) — по XP-18 это правильно. Цвета обоев и заставки. Тени меню.

## Проверка
- Менеджер паролей: точки в строках паролей на месте, шрифт как у интерфейса.
- Параметры → Оформление: карточки тем с ровными концентрическими углами.
- Окончание загрузки вспыхивает тем же зелёным, что и остальные «успехи» (`--ok`).
- Предпросмотр вкладки при наведении — без обводки, тень на месте; проверить в светлой и тёмной теме.
